# Hello

First val — just proving install → auth → create → deploy round-trips.

- `http.ts` — minimal HTTP val, returns "Hello, world!"

Live at [backspaces-hello.val.run](https://backspaces-hello.val.run/) — a
short custom subdomain instead of the default long hash-based branch URL
(`backspaces--<hash>.web.val.run`). Claimed via the pencil icon on the
code editor's HTTP bar (or triple-dots → Custom subdomain); free,
first-come-first-served, web-UI only like the cron schedule. Rules: DNS-safe
name, no leading/trailing/double dashes, 3–63 chars.

Originally claimed as `hello-backspaces`, then renamed to
`backspaces-hello` to match the other vals (`backspaces-<val>`). Renaming
is the same pencil-icon step. The old name stopped working at once (404),
and val.town keeps it reserved for a while so nobody else can grab it and
receive traffic meant for this val. The number of renames per endpoint is
limited.
